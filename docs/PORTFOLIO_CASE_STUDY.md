# CommerceLens — automated E-commerce Analytics & Sentiment

Role fit: Data Analyst / BI Analyst / Analytics Engineer.

Problem: Price movements, review tone and category comparisons are often difficult to reconcile.

Solution: I developed a complete CSV validation and data-quality pipeline, rule-based sentiment classifier, SQLite analytical warehouse and interactive Streamlit dashboard, supported by automated tests and SQL analytical queries.

Stack: Python, SQLite, SQL window functions, Pandas, Plotly, Streamlit, Matplotlib, unittest, GitHub Actions.

Scope: The deterministic starter demo has 12 fictional products over 120 days (1,440 product-day observations), plus fictional review examples. Ten visually designed SVGs accompany the README, and ten data-driven PNG charts can be produced locally.

Limits: Not a live retailer API, genuine sales results, published sentiment accuracy benchmark or production deployment.
